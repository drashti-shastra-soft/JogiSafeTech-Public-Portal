# 🛡️ JOGI SafeTech – Public Portal

**JOGI SafeTech Public Portal** is a professional, responsive web application developed for **JOGI SafeTech Pvt. Ltd.**, a safety consulting and risk management company based in Surat, Gujarat, India.

The website showcases the company's industrial safety services, process safety solutions, risk assessment capabilities, certifications, clients, and business information.

It provides visitors with an easy way to explore services and connect with the company through online inquiry and contact forms.

## 🌐 Live Website

**Visit Website:** [https://www.jogisafetech.com/](https://www.jogisafetech.com/)

## ✨ Key Features

- **Home Page:** Professional introduction to JOGI SafeTech.
- **About Us:** Company information, mission, vision, and founder message.
- **Services:** Detailed information about industrial safety and consulting services.
- **Process Safety:** Information about PHA, HAZOP, HAZID, PSM, and related services.
- **Risk Assessment:** Showcases HIRA, QRA, and JSA services.
- **Safety Audits:** Information about industrial, fire, electrical, and process safety audits.
- **Certifications:** Displays company certifications and accreditations.
- **Partners & Clients:** Showcases associated clients and organizations.
- **Testimonials:** Displays customer feedback and experiences.
- **Quick Inquiry:** Allows visitors to submit service inquiries.
- **Contact Us:** Provides company contact information and communication options.
- **SEO-Friendly Pages:** Helps improve website visibility in search engines.
- **Admin Panel:** Provides administrative functionality for website management.

## ⚙️ Getting Started

### Prerequisites

- Visual Studio
- Compatible .NET SDK
- NuGet Package Manager
- SQL Server (if required by the application)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/drashti-shastra-soft/JogiSafeTech-Public-Portal.git
```

**2. Navigate to the project directory**

```bash
cd JogiSafeTech-Public-Portal
```

**3. Open the solution**

Open the following solution file in Visual Studio:

```text
Jogisafetech.sln
```

**4. Restore NuGet Packages**

```bash
dotnet restore
```

**5. Configure Application Settings**

Review `appsettings.json` and configure the required application settings, connection strings, and other environment-specific values.

Do not commit production credentials, passwords, or sensitive configuration values to GitHub.

**6. Build the Project**

```bash
dotnet build
```

**7. Run the Application**

Select the `Jogisafetech` project as the startup project in Visual Studio and run the application.
